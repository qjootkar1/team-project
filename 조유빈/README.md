# 회계 분개장 분석 시스템 (담당: 조유빈)

본 프로젝트는 분개장 데이터 회계 분석 시스템 중 **조유빈** 담당 3개 핵심 기능의 독립 모듈화 및 통합 프로젝트입니다.

---

## 📌 조유빈 담당 기능 목록

| 요구사항 ID | 기능 ID | 기능 설명 | 페이지 파일명 | 주요 구현 내용 |
|---|---|---|---|---|
| **REQ-06** | **FUN-13** | **주요 증감 원인 요약** | `fun-13.html` | 전년 대비 급격한 증감 계정과목 추출, 원인 요약 카드 그리드, 상세 변동표, 증감 필터링 |
| **REQ-07** | **FUN-14** | **분석 결과 그래프 표시** | `fun-14.html` | 월별 매출·지출 라인 차트, 전년 대비 비교 차트, 계정과목별 지출 바 차트 (Pure SVG) |
| **REQ-07** | **FUN-15** | **분석 보고서 생성 및 다운로드** | `fun-15.html` | 결재란, 핵심 KPI, 4종 시각화 차트, AI 요약 의견이 통합된 A4 규격 PDF 실시간 인쇄/다운로드 |

---

## 🚀 파일 구성 및 아키텍처

- `index.html`: 메인 대시보드 및 각 기능별 페이지로의 리다이렉트 내비게이션 허브
- `fun-13.html`: [FUN-13] 주요 증감 원인 요약 전용 페이지 (개별 크롭/캡처 최적화)
- `fun-14.html`: [FUN-14] 분석 결과 그래프 표시 전용 페이지 (개별 크롭/캡처 최적화)
- `fun-15.html`: [FUN-15] 분석 보고서 생성 및 PDF 다운로드 전용 페이지 (A4 인쇄 최적화)
- `shared.js`: 공통 유틸리티 (포맷팅, 차트 렌더링 엔진, 샘플 데이터 세트, localStorage 캐시 연동)
- `style.css`: Pretendard 기반의 모던 디자인 시스템

## 🛠️ GitHub 작업 흐름 (Git Commands)

```bash
# 1. 깃 저장소 초기화 (최초 1회)
git init

# 2. 파일 스테이징 및 첫 커밋
git add .
git commit -m "feat: 조유빈 담당 기능(FUN-13, FUN-14, FUN-15) 구현 및 독립 페이지 구성"

# 3. 원격 리포지토리 연결 및 푸시
git branch -M main
git remote add origin <GitHub_저장소_URL>
git push -u origin main
```

## 🔄 데이터 연동 (n8n 및 타 팀원 모듈 연계)

- 브라우저 `localStorage`의 `accounting-n8n-v1` 및 `accounting-analysis-cache` 키를 공유하여, 김다은·이영언·채민서·손유석 팀원의 모듈과 무리 없이 결합할 수 있습니다.
- 데이터가 없는 초기 상태에서도 데모 데이터(`getMockData()`)가 내장되어 있어 단독 화면 캡처 및 검증이 가능합니다.
