# AccountScope - 김다은 담당 기능 프로토타입

## 포함 페이지
- `upload.html` — FUN-01 분개장 파일 업로드 (CSV/XLSX/XLS, 미리보기, 연도 감지, 로컬 등록)
- `data.html` — FUN-02 업로드 데이터 조회 (통합검색, 연도/파일/계정과목 필터, CSV 내보내기)
- `years.html` — FUN-03 연도별 데이터 관리 (연도별 거래 행/차변/대변 합계, 파일 관리 및 삭제)
- `index.html` — 간단한 시작/요약 페이지

## 실행
브라우저에서 파일을 직접 열기보다 프로젝트 폴더에서 로컬 서버를 실행하세요.

```bash
python -m http.server 8000
```
그다음 `http://localhost:8000` 접속.

Excel 파일 읽기에는 SheetJS CDN을 사용하므로 첫 로딩 시 인터넷 연결이 필요합니다. CSV는 기본 브라우저 기능으로 읽습니다.

## 데이터 저장/통합
현재 프로토타입은 동일 브라우저/동일 출처의 `localStorage`에 저장합니다. 실제 팀원 간 공유, n8n, PostgreSQL 연결은 아직 구현하지 않았습니다. 팀 통합 시 `common.js`의 저장/조회 부분을 공용 API로 교체하면 각 페이지 UI를 유지할 수 있습니다.

## 지원하는 대표 열 이름
- 거래일자: `거래일자`, `일자`, `전표일자`, `date`
- 계정코드: `계정코드`, `계정과목코드`, `account_code`
- 계정과목: `계정과목`, `계정과목명`, `account_name`
- 적요: `적요`, `거래내용`, `description`
- 거래처: `거래처`, `거래처명`, `customer`
- 차변: `차변`, `차변금액`, `debit`
- 대변: `대변`, `대변금액`, `credit`

원본 행은 그대로 보존합니다. 회사별 엑셀 양식이 다르면 열 매핑 기능을 추가해야 합니다.
