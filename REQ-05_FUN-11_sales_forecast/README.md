# 다음 연도 매출 예측

| 요구사항 ID | 기능 ID | 결과 |
| --- | --- | --- |
| REQ-05 | FUN-10 | 분개장에서 기준 연도 다음 해의 연간·월별 예상 순매출과 과거 연간 검증 오차를 계산 |

HTML, CSS, JavaScript만으로 실행합니다. 파일을 읽고 계산하는 작업은 브라우저 안에서 이루어집니다. Python은 로컬 웹서버를 실행할 때만 사용합니다.

## 실행

프로젝트 폴더에서 다음 명령을 실행하고 브라우저에서 [http://localhost:8000](http://localhost:8000)을 엽니다.

```sh
python -m http.server 8000 --bind 127.0.0.1
```

1. **분개장 파일**에서 UTF-8 CSV 또는 기존 분개장 JSON 백업을 선택합니다.
2. **자료 시작 연도**에는 1월부터 분개 입력을 마친 첫 해를, **기준 연도**와 **마감 월**에는 마지막으로 입력을 마친 기간을 넣습니다. 기준 연도 2026년을 선택하면 2027년을 예측합니다.
3. 기존 분개장에 기본 목록과 다른 매출 계정 이름이 있다면 **추가 매출 계정**에 분개장에 적힌 이름을 쉼표로 구분해 입력합니다.
4. 입력 완료에 체크하고 **예상 매출 계산**을 누릅니다. 결과에서 연간 예상액과 다음 연도 1~12월의 월별 예상액을 확인합니다.

**예시 분개장 불러오기**를 선택하면 2022년부터 2025년 12월까지의 예시가 열립니다. 이 예시의 2026년 예상 순매출은 11,358,000원입니다.

## 파일 형식

Excel 분개장은 **CSV UTF-8** 형식으로 저장한 뒤 사용합니다. 첫 줄에 헤더를 두고 전표의 계정별 분개를 한 줄에 기록합니다. 금액은 원 단위 정수이며, 거래 방향에 해당하는 한쪽 금액만 양수로 입력합니다. 빈 금액은 0으로 읽습니다.

```csv
날짜,계정과목,차변,대변
2025-01-15,현금,1000000,0
2025-01-15,상품매출,0,1000000
2025-02-03,매출환입,30000,0
```

JSON은 전표 배열 또는 `entries`에 배열을 담은 객체를 지원합니다. 전표 필드는 `date`, `account`, `debit`, `credit`이며 `id`는 선택입니다. 동일한 `id`가 집계 기간에 중복되면 오류가 표시됩니다. 한 번에 최대 50,000행과 연속된 최대 10년을 분석합니다.

## 예측 방식

- 순매출은 매출 계정에 기록된 **대변 − 차변**입니다. 상품매출, 제품매출, 용역매출 등과 매출환입, 매출에누리, 매출할인을 집계합니다. 차변에 기록된 환입과 할인은 순매출을 줄입니다.
- 월평균 연환산을 기본값으로 사용합니다. 과거 자료가 충분하면 전년의 남은 달 매출을 반영한 방식, 최근 두 해 평균, 전년 동기 대비 증감 반영 방식을 같은 과거 구간에서 비교합니다. 과거 예측은 각 기준 연도의 동일한 마감 월에서 계산하고 다음 해 실제 연간 매출과 비교합니다.
- 검증 자료가 있으면 최대 오차 30만 원 이내인 방식 중 평균 절대 오차가 가장 작은 방식을 우선합니다. 그 조건을 충족한 방식이 없으면 평균 절대 오차가 가장 작은 방식을 사용합니다.
- 참고 구간의 표시 폭은 과거 최대 절대 오차를 기준으로 ±10만~30만 원을 적용합니다. 과거 검증 자료가 부족하면 ±30만 원을 표시합니다. 실제 과거 오차는 별도 표시하며 미래 오차는 달라질 수 있습니다.
- 월별 예상액은 연간 예상액을 최근 최대 3개 완결 연도의 월별 순매출 비중에 따라 배분한 값입니다. 기준 연도는 12월까지 마감했을 때 포함합니다. 각 해의 월별 순매출이 0원 이하인 달은 비중 계산에서 0원으로 처리합니다. 비중을 계산할 수 있는 연간 자료가 없으면 12개월에 고르게 배분합니다. 1원 단위의 배분 차이를 조정해 월별 합계와 연간 예상액을 맞춥니다.
