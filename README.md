# AccountScope - 통합 회계 분석 및 경영 리포팅 시스템

본 프로젝트는 5인 팀원(김다은, 이영언, 채민서, 손유석, 조유빈)이 담당한 15개 전체 회계 분석 요구사항을 **김다은의 디자인 시스템(AccountScope)**을 기준으로 통합하고 표준화한 웹 애플리케이션입니다.

## 🚀 실행 방법

웹 브라우저에서 `index.html`을 열거나, 프로젝트 디렉토리에서 간단한 로컬 웹 서버를 실행합니다:

```bash
# Python 내장 웹 서버 실행 (포트 8000)
python -m http.server 8000
```
이후 브라우저에서 `http://localhost:8000`에 접속합니다.

- **샘플 데이터 원클릭 로드:** 사이드바 하단 또는 메인 화면의 **[샘플 데이터 로드]** 버튼을 클릭하면 2개년도(2023, 2024) 정밀 분개장 전표가 즉시 로드되어 모든 페이지의 동작과 차트를 바로 확인할 수 있습니다.
- **인쇄 및 PDF 다운로드:** `report.html` 상단의 **[📥 A4 PDF 다운로드 / 인쇄]** 버튼을 누르면 브라우저 인쇄 대화상자에서 깨끗한 A4 결재 서식으로 저장할 수 있습니다.
